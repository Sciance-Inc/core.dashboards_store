# Documentation website
> Helping dashboard developers, one README at a time.

## Prerequisites

### Install Node.js and Node Version Manager

The website is built with Node.js, Nuxt, and Docus. Install Node.js before running the website locally. We recommend using Node Version Manager to avoid version conflicts with other projects. If you already know Python and virtual environments, this workflow should feel familiar.

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.1/install.sh | bash # Install NVM
source ~/.bashrc # Reload bashrc
nvm install 22 # Install Node.js
```

## How to contribute

1. Install dependencies.

```bash
npm install
```

2. Start the website in development mode to preview your changes.

```bash
npm run dev
```
