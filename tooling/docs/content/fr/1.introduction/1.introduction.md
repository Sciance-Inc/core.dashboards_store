# Qu'est-ce que la Bibliothèque de tableaux de bord (le *Dashboards Store*)?

::alert{type="info"}
✨ La **Bibliothèque** est une collection de tableaux de bord *Power BI* et de *scripts* SQL permettant d'exploiter rapidement l'entrepôt de données d'un centre de services scolaire.
::

## Qu'est-ce qui est inclus?

La Bibliothèque regroupe:
* ⌨️ Le **code SQL** pour transformer les données provenant de vos bases de données.
* 📊 Les **tableaux de bord Power BI** pour visualiser les données transformées.

Les deux vont ensemble: les métriques et les règles d'affaires écrites ou calculées en SQL peuvent être réutilisées dans plusieurs tableaux de bord, ce qui fournit une vue uniforme et cohérente de vos données.

::alert{type="info"}
Les centres de services scolaires ne se ressemblent pas tous. Vous pourriez ne pas avoir besoin de certains tableaux de bord offerts par la Bibliothèque, ou vouloir ajouter les vôtres. **La Bibliothèque est entièrement personnalisable**: vous pouvez ajouter vos propres *scripts* SQL et tableaux de bord, ou modifier ceux qui existent avec de l'***overriding***. La Bibliothèque n'est que le point de départ!
::

## À qui s'adresse la Bibliothèque?
La Bibliothèque cible les centres de services scolaires franco-canadiens, mais peut être utilisée par toute organisation scolaire qui s'appuie sur le même modèle de données. Les analystes BI, les développeurs BI et les ingénieurs de données y trouveront une base solide sur laquelle bâtir. Pour utiliser `core.dashboards_store`, vous aurez besoin de connaître SQL, Linux et Git. Ces technologies peuvent faire peur, mais elles nous survivront probablement; autant apprendre à les utiliser.

## Sur les épaules de géants

La Bibliothèque s'appuie sur les meilleurs outils de la communauté *open source*. Sa pierre angulaire est [*dbt*](https://docs.getdbt.com/), un outil de transformation de données qui modernise l'écriture du code SQL. En utilisant ***dbt***, vous obtenez une syntaxe SQL moderne et agréable, ainsi qu'une manière gratuite de **documenter**, **tester** et **planifier** vos transformations. Si `JUnit` vous manque, vous allez aimer ***dbt***.

## Entièrement *open source*

La Bibliothèque est profondément ancrée dans la communauté *open source*, et elle est elle-même *open source*. Nous croyons que la meilleure façon de construire un bon produit est de le construire avec les utilisateurs, même si les écouter trop littéralement n'est pas toujours une stratégie gagnante. Nous cherchons toujours des contributeurs, parce que quelqu'un doit bien corriger mes bogues.
