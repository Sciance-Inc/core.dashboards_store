# Qu'est-ce que le Dashboards Store?

::alert{type="info"}
✨ Le **Dashboards Store** est une collection de *dashboards* *Power BI* et de *scripts* SQL permettant d'exploiter rapidement l'entrepôt de données d'un centre de services scolaire.
::

## Qu'est-ce qui est inclus?

Le Store regroupe:
* ⌨️ Le **code SQL** pour transformer les données provenant de vos bases de données.
* 📊 Les ***dashboards* Power BI** pour visualiser les données transformées.

Les deux vont ensemble: les métriques et les règles d'affaires écrites ou calculées en SQL peuvent être réutilisées dans plusieurs *dashboards*, ce qui fournit une vue uniforme et cohérente de vos données.

::alert{type="info"}
Tous les centres de services scolaires ne se ressemblent pas. Vous pourriez ne pas avoir besoin de certains *dashboards* offerts par le Store, ou vouloir ajouter les vôtres. **Le Store est entièrement personnalisable**: vous pouvez ajouter vos propres *scripts* SQL et *dashboards*, ou modifier ceux qui existent avec de l'***overriding***. Le Store n'est que le point de départ!
::

## À qui s'adresse le Store?
Le Store cible les centres de services scolaires franco-canadiens, mais peut être utilisé par toute organisation scolaire qui s'appuie sur le même modèle de données. Les analystes BI, les développeurs BI et les ingénieurs de données y trouveront une base solide sur laquelle bâtir. Pour utiliser `core.dashboards_store`, vous aurez besoin de connaître SQL, Linux et Git. Ces technologies peuvent faire peur, mais elles nous survivront probablement; autant apprendre à les utiliser.

## Sur les épaules de géants

Le Store s'appuie sur les meilleurs outils de la communauté *open source*. Sa pierre angulaire est [*dbt*](https://docs.getdbt.com/), un outil de transformation de données qui modernise l'écriture du code SQL. En utilisant ***dbt***, vous obtenez une syntaxe SQL moderne et agréable, ainsi qu'une manière gratuite de **documenter**, **tester** et **planifier** vos transformations. Si `JUnit` vous manque, vous allez aimer ***dbt***.

## Entièrement *open source*

Le Store est profondément ancré dans la communauté *open source*, et il est lui-même *open source*. Nous croyons que la meilleure façon de construire un bon produit est de le construire avec les utilisateurs, même si les écouter trop littéralement n'est pas toujours une stratégie gagnante. Nous cherchons toujours des contributeurs, parce que quelqu'un doit bien corriger mes bogues.
