::alert{type=info}
Suit les élèves de secondaire 5 quant à la possibilité d'obtenir un diplôme d'études secondaires selon le système J5.
::

# Déploiement
:badge[tag:diplome]{type="success"}
:badge[new in v0.19.0]

## Bases de données
Les bases de données `GPI` et `Jade` doivent être liées au projet. Consultez la section [lier une base de données](/fr/using/configuration/databases) pour plus d'informations.

## *Seed*
::alert{type=warning}
Une *seed* est requise pour que le *dashboard* fonctionne.
::

Le *dashboard* nécessite la *seed* `matiere_evalue`. Consultez la section [*seeding*](/fr/using/configuration/adapts-seeds) pour plus d'informations sur l'alimentation d'un *mart*. Cette *seed* est requise pour alimenter les matières sanctionnées. Comme vous n'avez pas besoin de la remplacer, vous pouvez simplement exécuter cette commande pour la créer: `dbt seed --select +tag:diplome`.
La *seed* est décrite dans `core.dashboards_store/seeds/dashboards/educ_serv/diplome/schema.yml`.

## *Marts*
Les *marts* suivants doivent être activés pour que le *dashboard* fonctionne. Consultez la section [activer un *mart*](/fr/using/configuration/enabling) pour plus d'informations.
* `educ_serv`


## Spécification du projet *dbt*
> Mettez à jour votre fichier `cssXX.dashboards_store/dbt_project.yml` avec l'extrait suivant.

```yaml
# cssXX.dashboards_store/dbt_project.yml
models:
    core_dashboards_store:
        marts:
            educ_serv:
                +enabled: True

        dashboards:
            educ_serv:
                diplome:
                    +enabled: True
        interfaces:
            gpi:
                +enabled: True
            jade:
                +enabled: True

vars:
  database_gpi: "Nom / IP de la base gpi"
  database_jade: "Nom / IP de la base jade"
```
