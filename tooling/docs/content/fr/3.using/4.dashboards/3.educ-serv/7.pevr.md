## Bases de données
La base de données `gpi` doit être liée au projet. Consultez la section [lier une base de données](/fr/using/configuration/databases) pour plus d'informations.

## *Marts*
Les *marts* suivants doivent être activés pour que le tableau de bord fonctionne. Consultez la section [activer un *mart*](/fr/using/configuration/enabling) pour plus d'informations.

- `educ_serv`

#### Spécification du projet *dbt*
> Mettez à jour votre fichier `cssXX.dashboards_store/dbt_project.yml` avec l'extrait suivant.

```yaml
# cssXX.dashboards_store/dbt_project.yml
models:
  core_dashboards_store:
    marts:
      educ_serv:
        +enabled: True
    dashboards:
      direction_generale:
        pevr:
          +enabled: true
    interfaces:
      gpi:
        +enabled: true
```

# Configuration

::alert{type=warning}
La configuration est optionnelle. Si vous ne fournissez pas de configuration, le tableau de bord utilisera la configuration par défaut.
::

## Personnaliser les indicateurs PEVR

> Cette table nécessite des *seeds*. Assurez-vous d'exécuter `dbt seed --full-refresh` pour les alimenter.

- Pour ajouter une liste d'indicateurs locaux à suivre:
  1. Ajoutez un fichier `.csv` dans `cssXX.dashboards_store/seeds/dashboards/direction_generale/pevr`. Il doit s'appeler `custom_indicateurs_pevr_meq.csv` et contenir les colonnes décrites dans `core.dashboards_store/seeds/dashboards/direction_generale/pevr/schema.yml`, qui décrit la *seed* `custom_indicateurs_pevr_meq`.
  2. Ajoutez un fichier `.csv` dans `cssXX.dashboards_store/seeds/dashboards/direction_generale/pevr`. Il doit s'appeler `custom_indicateurs_pevr_charl.csv` et contenir les colonnes décrites dans `core.dashboards_store/seeds/dashboards/direction_generale/pevr/schema.yml`, qui décrit la *seed* `custom_indicateurs_pevr_charl`.
  3. Déclenchez un rafraîchissement de vos *seeds*.

```bash
dbt seed --full-refresh
```

::alert{type=info}
Consultez la section [*seeds*](/fr/using/configuration/adapts-seeds) pour plus d'informations sur l'utilisation et l'alimentation des *seeds*.
::
