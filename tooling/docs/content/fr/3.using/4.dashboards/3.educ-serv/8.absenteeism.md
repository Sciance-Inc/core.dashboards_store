# Déploiement
:badge[tag:absenteeism]{type="success"}
:badge[new in v0.11.0]

## Bases de données
La base de données `gpi` doit être liée au projet. Consultez la section [lier une base de données](/fr/using/configuration/databases) pour plus d'informations.

## *Marts*
Les *marts* suivants doivent être activés pour que le *dashboard* fonctionne. Consultez la section [activer un *mart*](/fr/using/configuration/enabling) pour plus d'informations.

- `educ_serv`

#### Spécification du projet *dbt*
> Mettez à jour votre fichier `cssXX.dashboards_store/dbt_project.yml` avec l'extrait suivant.

```yaml
# cssXX.dashboards_store/dbt_project.yml
models:
  core_dashboards_store:
    marts:
      educ_serv:
        +enabled: True
    dashboards:
      educ_serv:
        absenteeism:
          +enabled: True
    interfaces:
      gpi:
        +enabled: True
```

## RLS
Les tables `report_filters` et `report_bris_de_service` exposent toutes deux les variables `id_eco` et `eco` comme points d'ancrage RLS.
Toutes les tables de rapport, sauf `report_bris_de_service`, dépendent de `report_filters`; en ajoutant la RLS sur `report_filters`, toutes les autres tables seront filtrées en conséquence.
