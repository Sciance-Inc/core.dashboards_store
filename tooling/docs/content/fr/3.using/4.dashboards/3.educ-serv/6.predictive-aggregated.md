---
title: Modélisation prédictive - agrégée
---

::alert{type=info}
Suit le nombre d'élèves à risque élevé de décrochage, de redoublement ou de non-diplomation à temps, et fournit un moyen de comparer les écoles.
::

::alert{type=danger}
Ce *dashboard* nécessite que les modèles de Sciance soient disponibles.
::

# Déploiement
:badge[tag:predictive_view_aggregated]{type="success"}
:badge[new in v0.7.0]

## Bases de données
La base de données `prodrome` doit être liée au projet. Consultez la section [lier une base de données](/fr/using/configuration/databases) pour plus d'informations.

## *Seed*
::alert{type=warning}
Une *seed* est requise pour que le *dashboard* fonctionne.
::

Le *dashboard* nécessite la *seed* `predictive_models_to_include`. Consultez la section [*seeding*](/fr/using/configuration/adapts-seeds) pour plus d'informations sur l'alimentation d'un *mart*. Cette *seed* sert à choisir les modèles prédictifs à inclure dans le *dashboard*.
La *seed* est décrite dans `core.dashboards_store/seeds/dashboards/educ_serv/predictive_view_aggregated/schema.yml`.

## Spécification du projet *dbt*
> Mettez à jour votre fichier `cssXX.dashboards_store/dbt_project.yml` avec l'extrait suivant.

```yaml
# cssXX.dashboards_store/dbt_project.yml
models:
  core_dashboards_store:
    dashboards:
      educ_serv:
        predictive_view_aggregated:
          +enabled: True
    interfaces:
      prodrome:
        +enabled: True

vars:
  database_prodrome: "Nom / IP de la base prodrome"
```
