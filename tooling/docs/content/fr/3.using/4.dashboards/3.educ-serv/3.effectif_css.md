title: Effectif des élèves
---

::alert{type=warning}
Suit une population définie au sein d'un centre de services scolaire. Le tableau de bord affiche le nombre total d'élèves dans chaque école.
::

# Déploiement
:badge[tag:effectif_css]{type="success"}
:badge[new in v0.7.0]

## Bases de données
La base de données `gpi` doit être liée au projet. Consultez la section [lier une base de données](/fr/using/configuration/databases) pour plus d'informations.

## *Marts*
Les *marts* suivants doivent être activés pour que le tableau de bord fonctionne. Consultez la section [activer un *mart*](/fr/using/configuration/enabling) pour plus d'informations.

- `educ_serv`

#### Spécification du projet *dbt*
> Mettez à jour votre fichier `cssXX.dashboards_store/dbt_project.yml` avec l'extrait suivant.

```yaml
# cssXX.dashboards_store/dbt_project.yml
models:
  core_dashboards_store:
    marts:
      educ_serv:
        +enabled: True
    dashboards:
      effectif_css:
        +enabled: true
    interfaces:
      gpi:
        +enabled: true
```


## Séparer les élèves du préscolaire régulier des élèves Passe-Partout

Vous pouvez configurer le tableau de bord pour séparer les élèves du préscolaire régulier des élèves Passe-Partout.
Pour cela, il faut alimenter un fichier `sql` qui identifie les élèves Passe-Partout.
Par défaut, aucun élève n'est identifié comme élève Passe-Partout. Vous devez faire de l'*overriding* sur le modèle `stg_check_passepartout` dans votre projet et fournir votre propre logique d'identification.
La documentation de `stg_check_passepartout` se trouve dans `core/models/dashboards/educ_serv/effectif_css/staging/stg_check_passepartout.sql` et dans `core/models/dashboards/educ_serv/effectif_css/staging/schema.yml`.

À partir de la version `v0.1.8`, le modèle `stg_check_passepartout` est prérempli lorsqu'un nouveau projet est créé avec le *template* `cookiecutter`.
