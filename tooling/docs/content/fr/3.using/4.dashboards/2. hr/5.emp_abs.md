# Absences des employé(e)s

> [!NOTE]
> Suivre les absences des employés dans les différents lieux de travail sur une période sélectionnée. Le tableau de bord affiche les taux d’absentéisme, les tendances hebdomadaires et les totaux par catégorie, avec des filtres pour la plage de dates, le type d’emploi, le lieu de travail, et plus encore.

## Bases de données
La base de données `paie` doit être liée au projet. Veuillez vous référer à la section [lier une base de données](/fr/using/configuration/databases) pour plus d'informations sur la façon de lier une base de données.

## *Marts*

Les *marts* suivants doivent être activés pour que le tableau de bord fonctionne. Consultez la section [activer un *mart*](/fr/using/configuration/enabling) pour plus d'informations.
- `human_resources`

## *Seeds*
Le tableau de bord utilise des *seeds* du *mart* ressources humaines et une *seed* propre au rapport. Consultez la section [*seeds*](/fr/using/configuration/adapts-seeds) pour plus d'informations.

Les *seeds* du *mart* nécessaires sont `etat_empl`, `type_absence`, `heure_quotidienne` et `code_paiement`.

La *seed* `secteur` est une dépendance optionnelle du rapport `emp_abs`. Elle alimente seulement le champ `secteur` de la table `report_absence`; si votre CSS ne contient pas de secteurs, vous pouvez la laisser vide.

```bash
dbt seed --select tag:human_resources tag:emp_abs --full-refresh
```

 ### etat_empl
  **Emplacement de la *seed*:** `seeds/marts/human_resources/schema.yml`
   **Champs obligatoires :**
   1. `etat_empl` : Code unique de l'état d'emploi
   2. `descr` : Description de l'état d'emploi
   3. `etat_actif` : Indique si l’employé est actif
   4. `empl_retr` : Indique si l’employé est retraité
   5. `empl_cong` : Indique si l’employé est en congé
   6. `cong_lt` : Indique si l’employé est en congé de longue durée
   7. `type_duration` : Type de durée : 0 = Courte durée, 1 = Longue durée
   **Nouveaux champs ☀**
---
 ### type_absence
  **Emplacement de la *seed*:** `seeds/marts/human_resources/schema.yml`
   **Champs obligatoires :**
   1. `motif_id` : Identifiant unique du motif d’absence
   2. `statut` : Statut du motif : 0 = actif, 1 = inactif
---
 ### secteur
 [!NOTE] Cette *seed* est fournie à titre optionnel. Si votre CSS ne contient pas de secteurs, il n’est pas nécessaire de l’inclure dans votre projet.
  **Emplacement de la *seed*:** `seeds/dashboards/human_resources/emp_abs/schema.yml`
  **Fichier à alimenter:** `cssXX.dashboards_store/seeds/dashboards/human_resources/emp_abs/secteur.csv`
   **Champs non obligatoires :**
   1. `lieu_trav` : Le numéro de l'unité administrative ou de l'école
   2. `secteur_id` : L'ID du secteur géographique ou subdivision de votre territoire
   3. `secteur_descr` : Description du secteur géographique ou subdivision de votre territoire
---
 ### heure_quotidienne
 **Emplacement de la *seed*:** `seeds/marts/human_resources/schema.yml`
   **Champs obligatoires :**
   1. `categorie_emp` : Catégorie d'emploi. Ex. : 1 = cadre, 2 = professionnel, etc.
   2. `poste_specifique` : Indique si le poste est spécifique (1) ou non (0)
   3. `corp_empl` : Code du corps d'emploi (4 caractères)
   4. `heure` : Nombre d'heures quotidiennes associées

 ### code_paiement
  **Emplacement de la *seed*:** `seeds/marts/human_resources/schema.yml`
   **Champs obligatoires :**
   1. `code_pmnt` : Le code d'un paiement
   2. `statut` : Statut du code de paiement | Longue durée => 1

## Spécification du projet *dbt*
### Configuration requise
1. Mettez à jour votre fichier  `cssXX.dashboards_store/dbt_project.yml` avec l'extrait de code suivant :
```yaml
# cssXX.dashboards_store/dbt_project.yml
models:
  core_dashboards_store:
    marts:
      human_resources:
        +enabled: True
    dashboards:
      human_resources:
        emp_abs:
          +enabled: true
    interfaces:
      paie:
        +enabled: true
```
