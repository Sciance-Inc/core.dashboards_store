## Bases de données

La base de données `paie` doit être liée au projet. Consultez la section [lier une base de données](/fr/using/configuration/databases) pour plus d'informations.

## *Seed*
::alert{type=warning} 1 *seed* est requise pour le fonctionnement du tableau de bord. ::

Le tableau de bord nécessite les *seeds* suivantes:

### etat_empl :
*Seed* obligatoire. Liste des états d'emploi du système de paie. Vous pouvez retrouver l'information dans la table `PAI_TAB_ETAT_EMPL` de votre système de paie. Pour le rapport de démission, une colonne indique `0` si ce n'est pas un état de démission, ou `1` si l'état d'emploi est une démission.
Emplacement de la *seed*: `seeds/marts/human_resources/schema.yml`. Champs obligatoires:

 1. etat_empl : Code unique de la qualification
 1. descr : Description du code de qualification
 1. etat_actif : Indique si l’employé est actif
 1. empl_retr : Indique si l’employé est retraité
 1. empl_cong : Indique si l’employé est en congé
 1. cong_lt : Indique si l’employé est en congé de longue durée
 1. empl_resi : Indique si l'employé a démissionné


```bash
dbt seed --full-refresh
```

## *Marts*
Les *marts* suivants doivent être activés pour que le tableau de bord fonctionne. Consultez la section [activer un *mart*](/fr/using/configuration/enabling) pour plus d'informations.

- `human_resources`

## Spécification du projet *dbt*
> Mettez à jour votre fichier `cssXX.dashboards_store/dbt_project.yml` avec l'extrait suivant.

```yaml
# cssXX.dashboards_store/dbt_project.yml
models:
  core_dashboards_store:
    marts:
      human_resources:
        +enabled: True
    dashboards:
      human_resources:
        resignation:
          +enabled: True
    interfaces:
      paie:
        +enabled: True
```
