::alert{type=info}
Ce tableau de bord liste les employés actifs du CSS. Il sert à calculer le nombre d'employés du CSS.
::

# Déploiement
:badge[tag:empl_actif]{type="success"}
:badge[new in v0.7.0]

## Bases de données
La base de données `paie` doit être liée au projet. Consultez la section [lier une base de données](/fr/using/configuration/databases) pour plus d'informations.

## *Marts*
Les *marts* suivants doivent être activés pour que le tableau de bord fonctionne. Consultez la section [activer un *mart*](/fr/using/configuration/enabling) pour plus d'informations.

- `human_resources`

## Spécification du projet *dbt*
> Mettez à jour votre fichier `cssXX.dashboards_store/dbt_project.yml` avec l'extrait suivant.

```yaml
# cssXX.dashboards_store/dbt_project.yml
models:
  core_dashboards_store:
    marts:
      human_resources:
        +enabled: True
    dashboards:
      human_resources:
        emp_actif:
          +enabled: True # Active les modeles du repo core
      interfaces: # Active l interface paie
        paie:
          +enabled: True
```

# Configuration
::alert{type=warning}
La configuration est optionnelle. Si vous ne fournissez pas de configuration, le tableau de bord utilisera la configuration par défaut.
::

## Configurer `nbrs_sem_dern_paie`

> La variable `nbrs_sem_dern_paie` est utilisée comme paramètre de récence. Elle filtre les employés dont la dernière paie est trop ancienne. Sa valeur par défaut est `1`.

La variable peut être remplacée en définissant `nbrs_sem_dern_paie` dans le fichier `dbt_project.yml`, dans la section `vars` et sous la clé `emp_actif`. Consultez la page [Variables configurables](/fr/using/configuration/variables) pour retrouver la valeur par défaut.

```yaml
# cssXX.dashboards_store/dbt_project.yml
vars:
  emp_actif:
    nbrs_sem_dern_paie: 1
```

## Un oeuf à deux jaunes: utiliser le *Report Builder* `empl_actif.rdl`

Un rapport SSRS est disponible pour exporter la liste des employés actifs du centre de services scolaire. Le fichier `emp_actif.rdl` se trouve dans `core.dashboards_store/reporting/emp_actif/emp_actif.rdl`.
