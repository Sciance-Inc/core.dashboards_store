::alert{type=info}
Suit le nombre d'employés retraités sur les 10 dernières années et fournit des prévisions pour les cinq prochaines années.
::

# Déploiement
:badge[tag:retirement]{type="success"}
:badge[new in v0.7.0]

## Bases de données
La base de données `paie` doit être liée au projet. Consultez la section [lier une base de données](/fr/using/configuration/databases) pour plus d'informations.

## *Marts*
Les *marts* suivants doivent être activés pour que le tableau de bord fonctionne. Consultez la section [activer un *mart*](/fr/using/configuration/enabling) pour plus d'informations.

- `human_resources`

## Spécification du projet *dbt*
> Mettez à jour votre fichier `cssXX.dashboards_store/dbt_project.yml` avec l'extrait suivant.

```yaml
# cssXX.dashboards_store/dbt_project.yml
models:
  core_dashboards_store:
    marts:
      human_resources:
        +enabled: True
    dashboards:
      human_resources:
        retirement:
          +enabled: True
    interfaces:
      paie:
        +enabled: True
```
