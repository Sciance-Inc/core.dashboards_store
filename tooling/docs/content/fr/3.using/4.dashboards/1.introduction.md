## Qu'est-ce qu'un *dashboard*?
Dans le contexte du Store, un `dashboard` est un fichier `.pbit`. Tous les *dashboards* sont stockés dans le dossier `core.dashboards_store/reporting`. Repérez le *dashboard* à déployer par son nom.

Pour déployer un *dashboard*, vous devrez:
1. L'activer, ainsi que toutes ses dépendances: *marts*, interfaces et ressources liées. Consultez la section [activer un *dashboard*](/fr/using/configuration/enabling) pour plus d'informations.
2. Le configurer au besoin en remplaçant certains modèles sur lesquels il repose ou en ajoutant des *seeds* personnalisées.
3. Déployer le fichier `Power BI` dans votre service *Power BI* et mettre à jour la connexion `pbit` afin qu'elle pointe vers votre base `<store_dev|store_prod>`.
