::alert{type=info}
Identifie les anomalies dans les données de votre école. Le *dashboard* rassemble une liste de problèmes et d'incohérences dans vos bases de données. Ce *dashboard* a été réalisé par le centre de services scolaire CSSPI (yé)!

::

# Déploiement
:badge[tag:anomalies]{type="success"}
:badge[new in v0.18.0]

## Base de données
Les bases de données `gpi` et `jade` doivent être liées au projet. Consultez la section [lier une base de données](/fr/using/configuration/databases) pour plus d'informations.

## *Marts*
Les *marts* suivants doivent être activés pour que le *dashboard* fonctionne. Consultez la section [activer un *mart*](/fr/using/configuration/enabling) pour plus d'informations.

- `educ_serv`

## *Adapters*
Un *adapter* doit être implémenté pour que le *dashboard* fonctionne. Consultez la section [lier un *adapter*](/fr/using/configuration/adapts-seeds).

## Spécification du projet *dbt*
> Mettez à jour votre fichier `cssXX.dashboards_store/dbt_project.yml` avec l'extrait suivant.

1. Activer les modèles et *dashboards* du *repo* *core*

```yaml
# cssXX.dashboards_store/dbt_project.yml
models:
  core_dashboards_store: # Active les modeles du repo core
    marts:
      educ_serv:
        +enabled: True
    dashboards:
      org_scolaire:
        anomalies:
          +enabled: True
    interfaces: 
      gpi:
        +enabled: True
      jade:
        +enabled: True

```

2. Activer l'*adapter*

Un *adapter* nommé `anml_stg_population` doit exister avec les deux colonnes suivantes: `fiche` et `id_eco`. Cet *adapter* sert à sélectionner les lignes pour lesquelles nous voulons suivre les anomalies.
