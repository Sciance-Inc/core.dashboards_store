# Configurer les variables dbt

Les variables permettent d'adapter les modèles de `core.dashboards_store` sans
remplacer leur SQL. Elles se définissent dans la section `vars` du fichier
`cssXX.dashboards_store/dbt_project.yml`.

::alert{type=warning}
`is_context_core` est une variable interne générée par le template. Ne la
modifiez pas.
::

## Variables disponibles

| Variable | Défaut | Utilisation |
| --- | --- | --- |
| `school_year_start_month` | `9` | Premier mois utilisé par `get_school_year` pour l'activité RH, sous forme d'un entier de `1` à `12`. |
| `current_year` | Déduit automatiquement | Remplace l'année courante calculée par `get_current_year`. |
| `database_paie` | À configurer | Nom pleinement qualifié de la base PAIE. |
| `database_gpi` | À configurer | Nom pleinement qualifié de la base GPI. |
| `database_jade` | À configurer | Nom pleinement qualifié de la base JADE. |
| `database_prodrome` | À configurer | Nom pleinement qualifié de la base PRODROME. |
| `interfaces.gpi.max_etapes` | `30` | Nombre maximal d'étapes générées depuis GPI. |
| `interfaces.gpi.max_periodes` | `20` | Nombre maximal de périodes générées depuis GPI. |
| `marts.educ_serv.recency.years_of_data_absences` | `10` | Nombre d'années d'absences conservées. |
| `marts.educ_serv.recency.years_of_data_grades` | `10` | Nombre d'années de résultats conservées. |
| `dashboards.res_epreuves.cod_css` | Requise pour `res_epreuves` | Expression utilisée pour limiter les résultats au CSS. |
| `emp_actif.nbrs_sem_dern_paie` | `1` | Nombre de semaines accepté depuis la dernière paie. |
| `res_scolaires.threshold` | `70` | Seuil de réussite élevée, en pourcentage. |

Les variables `database_*` sont détaillées dans la page
[Lier les bases de données](/fr/using/configuration/databases). Les variables
propres à un tableau de bord sont également expliquées dans la page de ce
tableau de bord.

## Remplacer un défaut de Core

Placez les variables propres au package sous la clé `core_dashboards_store`.
Par exemple, pour une année scolaire qui commence en juillet :

```yaml
# cssXX.dashboards_store/dbt_project.yml
vars:
  core_dashboards_store:
    school_year_start_month: 7
```

Sans cet override, Core utilise septembre. Une valeur inférieure à `1`,
supérieure à `12` ou non entière provoque une erreur de compilation explicite.
