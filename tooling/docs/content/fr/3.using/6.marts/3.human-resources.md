# *Seeds*

## *Seeds* obligatoires
::alert{type=warning}
Ces *seeds* doivent être renseignées pour que l'*ETL* fonctionne.
::

::alert{type=success}
Si vous avez créé votre Bibliothèque de tableaux de bord (le *Dashboards Store*) avec le *template* `cookiecutter`, les dossiers `cssXX.dashboards_store/seeds/marts/human_resources/` contiennent déjà des *seeds* préremplies pour vous aider à démarrer. Vous devez seulement mettre à jour les fichiers `csv` avec vos règles d'affaires.
::

Le tableau suivant présente les définitions de *seeds* requises et le chemin où placer les fichiers `csv`.

| Chemin de la définition YAML de la seed | Où l'enregistrer | Nom des seeds à implémenter | Portée |
| --- | --- | --- | --- |
| `core.dashboards_store/seeds/marts/human_resources/schema.yml` | `cssXX.dashboards_store/seeds/marts/human_resources/*.csv` |  etat_empl, stat_eng | *Mart* ressources humaines |
| `core.dashboards_store/seeds/marts/human_resources/schema.yml` | `cssXX.dashboards_store/seeds/marts/human_resources/*.csv` | heure_quotidienne, type_absence, code_paiement | Modèles d'absences du *mart* ressources humaines |
| `core.dashboards_store/seeds/marts/human_resources/schema.yml` | `cssXX.dashboards_store/seeds/marts/human_resources/*.csv` | secteur | Tableaux de bord d'absences des ressources humaines |

::alert{type=info}
**Démarrer avec les *seeds*.** Consultez le dossier `analyses/bootstrap` de votre nouveau *repo*. Vous y trouverez des requêtes prêtes à l'emploi pour préalimenter les *seeds*.
::

# *Adapters*

## *Adapters* obligatoires
::alert{type=warning}
Ces `adapters` doivent être renseignés pour faire rouler les modèles des ressources humaines qui consomment les populations élèves.
::

Le tableau suivant présente les définitions d'*adapters* requises et le chemin où placer les fichiers `sql`.

| Chemin de la définition YAML de l'*adapter* | Où l'enregistrer | Nom de l'*adapter* à implémenter | Portée |
| --- | --- | --- | --- |
| `core.dashboards_store/models/marts/human_resources/staging/adapters.yml` | `cssXX.dashboards_store/models/marts/human_resources/staging/*.sql` | stg_ele_primaire_reg_raw, stg_ele_secondaire_reg_raw | Modèles ressources humaines taggés `efficacite` |

Ces populations `raw` ressemblent aux populations régulières des services éducatifs, mais elles doivent aussi inclure les élèves inactifs. Évitez donc d'y recopier automatiquement le filtre d'élève actif utilisé dans les populations `educ_serv`.
