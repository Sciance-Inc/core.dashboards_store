# Introduction

Cette section vous aidera à adapter le Store à vos besoins.

Si vous découvrez le **Store**, vous devriez probablement suivre ce parcours:
* Commencez par configurer les [*seeds* et *adapters* de vos *marts*](/fr/using/marts/marts)
* Activez vos *marts* avec [l'activation d'une ressource](/fr/using/configuration/enabling.md)
* Choisissez un *dashboard* qui vous intéresse et configurez-le
* Exécutez l'*ETL*

::alert{type="warning"}
Tous les *marts* dont dépend un *dashboard* doivent être correctement configurés pour que le *dashboard* fonctionne. Cela inclut les `seeds` et `adapters` requis. Consultez la section [configuration des *marts*](/fr/using/marts/marts) pour plus d'informations.
::
