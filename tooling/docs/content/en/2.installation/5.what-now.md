# You did great! 🥳
You have a working `cssXX.dashboards_store` dbt project that can be used to populate the Store's database. Unfortunately, you are not done yet: you still have to configure the `cssXX.dashboards_store` project and run the ETL.


## What's done
::list{type="success"}
- Configuring my machine
- Cloning the repo and installing the environment
- Configuring the database connection
::



## What's left 🛠️
::list{type="warning"}
- **Linking the interfaces** to the source databases
- **Populating the seeds**. Seeds are required to configure several dashboards and marts.
- **Enabling dashboards**. That's the whole point, isn't it?
::

::alert{type="info"}
Refer to the "User guide -> Configuration" section to learn how to configure `core.dashboards_store`.
::
