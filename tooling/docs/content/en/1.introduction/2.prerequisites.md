# What do I need?

::alert{type="warning "}
Both **users** and **developers** should be familiar with [dbt](https://docs.getdbt.com/) and [Power BI](https://powerbi.microsoft.com/). If you are not, we recommend that you read the [dbt](https://docs.getdbt.com/) documentation before going any further.
::

# Your own personal Linux
::alert{type="warning"}
**dbt** and **Git** are easier to use on Linux than on Windows. If you don't have access to a *nix machine you can experiment with, you should set up your own personal Linux with **Windows Subsystem for Linux (WSL)**.
::

## How to set up WSL?
> It's paramount that you follow the instructions for **Windows Subsystem for Linux Version 2**. The first version was buggy as hell.

* [Install WSL2](https://learn.microsoft.com/en-us/windows/wsl/install)
* [Install Ubuntu on WSL2](https://ubuntu.com/tutorials/install-ubuntu-on-wsl2-on-windows-11-with-gui-support#1-overview)

You won't necessarily need Ubuntu's GUI for your work, but it's good knowledge to have anyway.

::alert{type="info"}
We advise using **Ubuntu**, but you'll be fine with any distro, provided you know how to use it.
::
