# Introduction

This section will help you tuning the Store to your own needs. 

If you're new to the **Store**, you should probably follow this journey:
* Start by configuring your [marts' seeds and adapters](/en/using/marts/marts)
* Enable your marts by [enabling a resource](/en/using/configuration/enabling.md)
* Choose a dashboard you like and configure it.
* Run the ETL.

::alert{type="warning"}
All marts a dashboard depends on must be properly configured for the dashboard to work. This includes any required `seeds` and `adapters`. Please refer to the [mart configuration](/en/using/marts/marts) section for more information.
::
