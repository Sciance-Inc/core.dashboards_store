::alert{type=info}
Tableau de bord permettant d’évaluer l’efficacité des ressources allouées en fonction des divers besoins des milieux et de la réussite éducative des élèves.
::

# Déploiement

:badge[tag:efficacite]{type="success"}

La base de données `paie` doit être liée au projet. Veuillez vous référer à la section [lier une base de données](/en/using/configuration/databases) pour plus d’informations sur la façon de lier une base de données.

La base de données `gpi` doit être liée au projet. Veuillez vous référer à la section [lier une base de données](/en/using/configuration/databases) pour plus d’informations sur la façon de lier une base de données.

## Magasin

Les marts suivants doivent être activés pour que le tableau de bord fonctionne. Veuillez vous référer à la section [activer un magasin](/en/using/configuration/enabling) pour plus d’informations sur la façon d’activer un magasin.

- `human_resources`

## Spécificité du projet dbt

> Mettez à jour votre fichier `cssXX.dashboards_store/dbt_project.yml` avec l’extrait suivant.

```yaml
# cssXX.dashboards_store/dbt_project.yml
models:
  core_dashboards_store:
    marts:
      human_resources:
        +enabled: true
    dashboards:
      human_resources:
        efficacite:
          +enabled: true
    interfaces:
      paie:
        +enabled: true
      gpi:
        +enabled: true
```

# Configuration

::alert{type=warning}
La configuration est facultative. Si vous ne fournissez aucune configuration, le tableau de bord utilisera la configuration par défaut.
::

## Configurer la seed `eff_categories_emploi`

::alert{type=info}
Veuillez vous référer à la section [seeds](/en/using/configuration/adapts-seeds) pour plus d’informations sur la façon d’utiliser et de renseigner les seeds.
::

> Par défaut, la seed `core.dashboards_store/seeds/dashboards/human_resources/efficacite/eff_categories_emploi.csv` est utilisée si aucune seed personnalisée n'a été créée dans le répertoire `cssXX.dashboards_store`. Nous vous recommandons fortement de créer cette seed et de la configurer avec un employé du service des ressources humaines.

Pour créer la seed personnalisée, dirigez-vous dans le répertoire `cssXX.dashboards_store/seeds/dashboards/human_resources/efficacite` puis créez le fichier `eff_categories_emploi_personnalises.csv`. Vous devez vous fier à la définition décrite dans le schéma de la seed situé dans `core.dashboards_store/seeds/dashboards/human_resources/efficacite/schema.yml`.

::alert{type=warning}
La configuration est obligatoire. Si vous ne fournissez aucune configuration, le tableau de bord ne va pas s'exécuter.
::

> Vous devez créer les quatre seeds suivantes dans le répertoire `cssXX.dashboards_store/seeds/dashboards/human_resources/efficacite` :

-> `eff_coefficients_premier_axes`
-> `eff_lieu_trav_to_lieu_jumele`
-> `eff_ecole_gpi_to_lieu_jumele`
-> `eff_reporting_configuration`

Comme spécifié ci-dessus, la définition des seeds est décrite dans le schéma situé dans `core.dashboards_store/seeds/dashboards/human_resources/efficacite/schema.yml`.

> Pour peupler la seed `eff_coefficients_premier_axes`, vous devez exécuter le script Python situé dans `core.dashboards_store/analyses/dashboards/efficacite/Dashboard_efficacite_extract_coeff.py`. Assurez-vous ensuite d'inscrire les données dans les bonnes colonnes de la seed.

> Pour peupler `eff_lieu_trav_to_lieu_jumele`, extrayez les `lieu_trav` de `i_pai_tab_lieu_trav`, puis associez chacun au `lieu_jumele` utilisé dans le tableau de bord.

> Pour peupler `eff_ecole_gpi_to_lieu_jumele`, extrayez les codes école de `i_gpm_t_eco`, puis associez chacun au `lieu_jumele` utilisé dans le tableau de bord. Par exemple, l'école satellite 042 peut être associée au lieu parent 005 sans imposer de correspondance avec un lieu de travail Paie.

> Pour peupler la seed `eff_reporting_configuration`, vous devez référencer un `lieu_jumele` du mapping GPI.
Si vous décidez qu'une école n'est pas comparable, vous pouvez l'exclure avec 0, sinon 1.
Si plusieurs écoles GPI sont associées au même `lieu_jumele`, nous recommandons fortement d'écrire le nom et la catégorie du lieu parent. Selon l'exemple décrit ci-dessus :

005,1,(005) - Saint-Paul,École primaire
