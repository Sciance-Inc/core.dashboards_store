# Déploiement
:badge[tag:pevr]{type="success"}

## Bases de données

Les bases de données `gpi` et `jade` doivent être liées au projet. Veuillez consulter la section [lier une base de données](/en/using/configuration/databases) pour plus d'informations sur la manière de lier une base de données.

## Marts

Les marts suivants doivent être activés pour que le tableau de bord fonctionne. Veuillez consulter la section [activation d'un mart](/en/using/configuration/enabling) pour plus d'informations sur la manière d'activer un mart.
* `educ_serv`

#### Spécifications du projet dbt
> Mettez à jour votre fichier `cssXX.dashboards_store/dbt_project.yml` avec l'extrait suivant

```yaml
# cssXX.dashboards_store/dbt_project.yml
models:
  core_dashboards_store:
    marts:
      educ_serv:
        +enabled: True
    dashboards:
      direction_generale:
        pevr:
          +enabled: true
    interfaces:
      gpi:
        +enabled: true
      jade:
        +enabled: true
```

# Configuration
Cette table nécessite quelques seeds. Assurez-vous d'exécuter `dbt seed --full-refresh` pour peupler les seeds.

::alert{type=info}
## Personnalisation de l'indicateur PEVR
* On vous conseille **fortement** de personnaliser vos propres numéros d'indicateurs, si applicable, et les cibles. Vous devez donc créer les seeds suivantes :
  1. Ajoutez un fichier `.csv` dans votre dossier `cssXX.dashboards_store/seeds/dashboards/direction_generale/pevr`. Le fichier doit être nommé `custom_cibles_indicateurs_annuelles_pevr.csv`. Le fichier doit être rempli avec les colonnes décrites dans `core.dashboards_store/seeds/dashboards/direction_generale/pevr/schema.yml` (fait référence à la seed `custom_cibles_indicateurs_annuelles_pevr`). Vous pouvez vous inspirer de la seed déjà existante dans
  `core.dashboards_store/seeds/dashboards/direction_generale/pevr/cibles_indicateurs_annuelles_pevr.csv`

  2. Ajoutez un fichier `.csv` dans votre dossier `cssXX.dashboards_store/seeds/dashboards/direction_generale/pevr`. Le fichier doit être nommé `custom_indicateurs_pevr_meq.csv`. Le fichier doit être rempli avec les colonnes décrites dans `core.dashboards_store/seeds/dashboards/direction_generale/pevr/schema.yml` (fait référence à la seed `custom_indicateurs_pevr_meq`). Vous pouvez vous inspirer de la seed déjà existante dans
  `core.dashboards_store/seeds/dashboards/direction_generale/pevr/indicateurs_pevr_meq.csv`

  3. Ajoutez un fichier `.csv` dans votre dossier `cssXX.dashboards_store/seeds/dashboards/direction_generale/pevr`. Le fichier doit être nommé `custom_indicateurs_pevr_charl.csv`. Le fichier doit être rempli avec les colonnes décrites dans `core.dashboards_store/seeds/dashboards/direction_generale/pevr/schema.yml` (fait référence à la seed `custom_indicateurs_pevr_charl`). Vous pouvez vous inspirer de la seed déjà existante dans
  `core.dashboards_store/seeds/dashboards/direction_generale/pevr/indicateurs_pevr_charl.csv`

Si vous êtes à l'aise avec l'overriding, vous pouvez également créer vos propres indicateurs en réutilisant les données du core.

Si le concept d'`overriding` est nouveau pour vous, veuillez lire [cette page](/en/using/configuration/overriding).
::
